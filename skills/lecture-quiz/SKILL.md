# Lecture quiz

Course notes: https://skojaku.github.io/adv-net-sci/

The lesson folder name is the module id. A folder named `m03-robustness` uses these pages:

- https://skojaku.github.io/adv-net-sci/m03-robustness/01-concepts.html
- https://skojaku.github.io/adv-net-sci/m03-robustness/02-coding.html
- https://skojaku.github.io/adv-net-sci/m03-robustness/03-exercises.html

Same pattern for every module: `https://skojaku.github.io/adv-net-sci/<folder>/01-concepts.html`. If the folder is not a module, ask which module and give the index link. Do not guess the topic.

## What to do

1. Fetch the concepts page. Fetch the exercises page too if the concepts page has little to ask about. Use a fetch tool. Do not write the quiz from memory.
2. Tell the student which page you read, as a clickable link, before the first question.
3. Write five questions. Each question defines every term it uses, names the object, and includes the numbers. A student who sees only that one question can answer it.
4. Do not print the answers in the same message. Ask them to try question 1. After they answer, say whether it matches the note, in plain words, and point at the heading you used.
5. Do not copy an open Pair Notebook checkpoint question, and do not give that checkpoint's answer.
6. If they say they are sitting an exam, stop. No quiz, no hints.
